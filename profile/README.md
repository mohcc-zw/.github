## About

This organization hosts open-source and internal software projects developed
for or by the **Ministry of Health and Child Care (MOHCC), Zimbabwe**, under
the oversight of the ICT Directorate.

Our work here supports the Ministry's digital health initiatives, including
information systems, data tools, and public health technology used across
national, provincial, and district health facilities.

## Repository guidelines

- See [`CONTRIBUTING.md`](../CONTRIBUTING.md) before opening a pull request.
- See [`CODE_OF_CONDUCT.md`](../CODE_OF_CONDUCT.md) for expected conduct in all project spaces.
- See [`GOVERNANCE.md`](../GOVERNANCE.md) for how decisions get made across these repositories.
- See [`SECURITY.md`](../SECURITY.md) to report a vulnerability — please do not open a public issue for security matters.
